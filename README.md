En este proyecto usamos varias tecnologías para poder desarrollarlo entre ellas PHP, HTML, JS, CSS , XAMPP y el MySQL.
El PHP lo usamos para poder insertarle a la base de datos los campos y su contenido, también lo usamos para poder conectar la base de datos con las paginas donde se mostraran la información guardada.
EL HTML lo usamos para darle la base a la paginas, junto al CSS le dimos el estilo a la pagina y que se vea bonita y única, y el JS lo usamos para darle animaciones y darle la parte lógica a las paginas.
El XAMPP lo usamos para levantar el servidor para poder usar la base de datos con el APACHE y el MySQL.
El MySQL es el servidor local donde ejecuto la base dedatos.
